## What this measures

Exercise the installed, patched `HaulGeneral` workgiver's real `HasJobOnThing(pawn, source, forced:false)` entry. Separate four facts: a query was made; a bulk candidate was constructed or reused; a job actually became current and executed; physical cargo was picked up and delivered. A successful query is not a successful haul.

The fixture should have explicit `baseline-gap` and `satisfied` modes. The former requires the published counter/backoff defect while all fixture controls pass. A missing candidate, bad binding, unexpected actual job, altered source, failed callback or timeout is inconclusive/failure, never the expected gap. The corrected mode requires no completed-loop counter, warning or backoff from queries, plus working automatic hauling. Planning-cache entries and allocated candidate Job IDs are legitimate query effects; the requirement is not that querying allocates or caches nothing.

## Source and installed API evidence

## Recommended product correction and its boundaries

Remove completed-recurrence accounting from bulk planning. Do not merely move `NoteBulkAnchor` to `StartJob` or reservations, change the warning text, increase the threshold, or debounce same-pawn/tick calls. None proves an executed net-zero return.

Resolve it through actual deliveries and terminal cleanup; count a completed net-zero return only when tracked cargo demonstrably returns to the same source context without useful delivery. A successful JobCondition alone is insufficient, especially across bulk pickup and the separate unload job.

Legitimate source relocation, delivered quantity, partial absorbs and changed source context are progress/reset conditions. Cancellation before pickup or an unresolved/interrupted attempt cannot become a completed-loop count. Handle split/merge lineage and parallel pawns explicitly; if attribution is unknown, report unknown rather than assert another mod moved an item. Count each completed attempt once, keep state bounded, and clear it through existing game-load hygiene. Diagnostics should state the actual observed quantity, source/destination and outcome; foreign causation requires separate evidence.

B1 certifies that probing cannot manufacture recurrence and that healthy hauling still works. It cannot by itself certify that the replacement still bounds a genuine successful return loop.

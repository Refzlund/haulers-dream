## Recurrence and fixture lessons

- **Queries are not executed work.** F43's old warning counter treated repeated candidate scans as recurrence; F15/F17 still require actual physical jobs. Preserve actual failure/backoff controls and use progress/owner/placement evidence.
- **Transient native state matters.** F24's one-tick `Wait_MaintainPosture` was a transition, not meaningful idle. Observe native Start/End boundaries before making scheduling decisions. Keep emergency, interval and full-capacity triggers distinct.
- **Callbacks can throw after moving cargo.** F11/F12 exact split/merge pieces may change before a return value or placedAction exists. Preserve original exception and observed partial physical progress; never assume false means zero movement, or find replacement stock by def.
- **Save order and custody matter.** F41 forward unlink was insufficient when the reciprocal bill had already serialized. F12/F13 need genuine current/queued IDs, durable order intent, native source/shelf references and pre-tick equality. Do not repair in the fixture to make a load pass.
- **One defect is not every similar report.** F20 hysteresis, F18 concurrent capacity, F16 erratic stocking and F15/F17 loops have separate acceptance. F25 component persistence does not recover lost historical metadata. Provider presence is not causation.
- **Native source governs test setup.** Silver stack limit is500, Steel75; full-stack hauling can respawn the original object instead of destroying it. A robot already at its station may synchronously contain itself without a return job. Native drafter components appear after spawn. Native languages may use legacy folder names/TAR metadata. Preserve failed fixtures and narrow the oracle to actual API semantics.
- **Read-only observers must really be read-only.** A Harmony `object[] __args` postfix overwrote actual out values in F40; use typed named out parameters. Job objects may be pooled/cleared during an inline start, so capture immutable entry identity. Do not call pawn-map-dependent permission APIs after despawn. IMGUI may consume/change Event.current; observe before use and require actual product control success.
- **Quicktest world state is not deterministic temperature.** A controlled tile mean plus cache clear did not immediately warm cached rooms. Warm a declared unroofed arena through bounded normal ticks before actors/cargo, then verify actual cell/room temperatures and medical fitness. Do not heal actors, clamp room fields or bypass product medical guards. Saved environmental choices must be observed honestly on reload.
- **Rendering/input has several independent gates.** Early viewport guards use native Prefs field names;1024×768/windowed may not render while hidden. A control can succeed even when a later Root observer misses the consumed event. Inspect actual receipts, events and PNGs before blaming focus. F12 prompt text hidden behind HUD is a real rendering defect despite passing quantity/state assertions; native overlay plus opaque backing is now verified. Win32 posted key/mouse messages do not prove Unity polled input: preserve the failed Shift/checkbox cases and inspect the actual native predicates rather than synthesizing success.
- **Fixture successors are real inputs.** Native job completion can immediately start unrelated work before the next observer update. The F13 partial-cancel failure was already holding a different resident stack before Cancel. A real queued native Wait preserves hands and allows stable standalone observations; do not repair cargo or suppress scheduling. Current-job destination exclusion can refuse a second command before any exclusive ledger row exists.
- **Capacity lower bounds must preserve debts.** F13 pooled scans are bounded at200; truncated zero cannot prove a late selected shelf is full. Its bounded selected-shelf floor still deducts ordinary same/cross-def shared claims and excludes native/exclusive incoming cells. Do not substitute raw physical room or count a reserved cell twice.
- **No unsupported diagnosis from a test harness.** Controlled corruption and injected callback failures are explicitly synthetic inputs into actual native operations. They demonstrate containment/repair behavior, not proof a named provider caused the reporter's incident.

## Bounded flow alternative under independent investigation

For a fixed immutable selected origin or union of origin classes, put selected quantity x on each physical history edge of observed quantity T, with 0 <= x <= T. Fix selected birth injections from actual origin budgets, conserve x at every transformation, and retain every live and accounted terminal frontier capacity. The complementary quantity is T-x. A complete quantity-conserving physical DAG therefore suggests a single-commodity representation for the selected class against all other material.

The proposed numerical query is the minimum and maximum selected quantity in a specified set of frontier fragments. It must send the entire selected birth quantity, not merely find an attractive partial flow. A greedy maximum to selected sinks followed by an unrelated remainder flow is not assumed correct; residual rerouting and feasibility of complete flow must be proved. A bounded min-cost complete flow with cost on selected-frontier edges is a candidate, subject to independent correctness and cost review. The implementation must not infer feasibility from an empty solution set, incomplete graph, missing terminal capacity or a truncated solver.

This possible solver answers fixed-label physical attribution only. Pickup-time return certificates and conditional history advancement are a separate causal layer. A later parent closure cannot retroactively relabel a child's earlier pickup. Any relabeling operation must specify which previously proved quantity class it transforms, and preserve mixed classes when only bounds are known. A correct fixed-origin flow solver alone cannot establish serial recurrence.

Start from explicit engineering bounds (up to128 history nodes per affected component, further origin/fragment limits from the parent design) and measure actual work and allocations before selecting final limits. Bound edge scans/augmentations and retained history, not just the input-array length. Quantities must not induce one iteration per unit. Candidate queries read a published bounded result and never run a solver or mutate lineage. Unrelated native transfers take only an inactive-membership check; mutation and scheduled solve work stay within the affected component. This is not a claim that exact optimization has one linear-time pass; the general objective can encode matching. A cap, unknown transformation or timeout produces explicit unresolved coverage and cannot reset evidence into a claim that a loop was disproved.

# Activity selection — draft pending native verification

In Custom Alerts, add **current action**, open its dropdown, choose **all options**, then select **gathering items into inventory**. Enable the alert after creating it and choose the map/count/delay you want.

The default list shows activities currently available on the map, so this entry can be hidden when nobody is gathering. All options exposes the saved job selection even then.

The selection matches the currently running Hauler's Dream bulk-gathering job, including explicit single-stack pickup. An order waiting in the queue, a separate unload job or ordinary native hand-hauling does not match. It selects current activity, not a separate WorkGiver or a sweep-only command filter.

Current package identities and pending actual validation are in README.md. This guidance has not been posted externally.

# F35 wording and proposed player guidance

The four existing setting values were updated in all 16 languages: `HaulersDream.Setting.HaulTamedSlaughter`, `HaulTamedSlaughterDesc`, `HaulWildKills`, and `HaulWildKillsDesc`. The labels now distinguish colony-animal carcasses from wild-animal carcasses. The descriptions cover the implemented Allow Tool and Keyz' Allow Utilities finish-off hooks, preserve the interrupted-hunt and completed-hunt distinction, and state that the haul goes behind existing orders only when the carcass is allowed and reachable storage accepts it.

`localization.diff` records only this task's changes, against the current files including earlier pending edits. `localization-check.json` contains all 64 before/after values: all 16 XML files parsed, no keys were added or removed, and every byte outside those four values stayed unchanged, including encoding/newlines and unrelated pending translations. This is XML/content verification, not a new rendered-language or native gameplay test.

The later native-provider review narrowed the colony description: Keyz rejects colony animals, while Allow Tool permits friendly finish-off targets only through its own guarded path. All 16 `HaulTamedSlaughterDesc` values now name only Allow Tool, qualified by the tool permitting the target. The wild description and both labels remain unchanged. `tamed-provider-amendment.diff` / `.json` retain this exact 16-value correction; `localization-amended.diff` is the complete current 64-value diff. Its original four-key baseline was reconstructed and hash-matched for every language. No other bytes, keys or pending translations changed. The original first-version artifacts remain historical rather than being overwritten.

`README.suggested.patch` and `COMPATIBILITY.suggested.patch` are proposed documentation hunks only; neither target document was edited by this task. `finish-off-hauling.md` is the proposed changeset, also retained here rather than installed in `.changeset`.

Scope follows `SlaughterHaul.FinishOff.cs` and the unchanged shared `SlaughterHaul.TryAppendHaul`: the same eligible killer receives one follow-up at the queue's end; forbidden corpses, unavailable storage and existing corpse-haul jobs prevent an extra job. Finish-off support names only the two inspected providers, including Keyz's inherited strip-and-finish path. Colony animals use the tamed setting, factionless wildlife uses the wild setting, and another faction's animals are excluded. Existing native slaughter and clean-hunt handling remains independent. Storage/reservations can change before the queued job starts, so the wording does not promise immediate or guaranteed delivery.

The implementation has source/compile evidence; the provider-native baseline/candidate fixture is still pending. These edits do not close F35 or claim support for arbitrary finish-off providers or Multiplayer. Parent should adopt the proposed player-document hunks only with the final report disposition.

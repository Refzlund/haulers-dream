- `Patch_ShouldDoNow.Prefix`: suspended means false. Otherwise `producedThisCycle < amountPerCycle` is immediately eligible, regardless of old timestamp. A completed cycle remains false until a query at `lastCycleCompletedTick + intervalDays * 60000`; that query resets the count to zero. There is no independent periodic timer tick.
- `Patch_NotifyIteration.Postfix`: one increment per recipe iteration. At or above configured amount it writes the current completion tick. Therefore two x4 meal iterations mean eight meals, not two. Another pawn's already-started job is not cancelled by this prefix; do not attribute possible upstream concurrent overshoot to HD without its baseline. Concurrency is outside this bounded scenario.
- `ExposeData` persists all four fields and the component's string-ID/deep-value dictionary. `FinalizeInit` removes dictionary entries whose IDs are not present in current map bill stacks. Actual saved map/bench/bill identity is therefore necessary to establish restart behavior; a standalone DTO/component roundtrip is insufficient.

Its actual execution still needs PB-alone and candidate receipts; this authoring does not claim that execution occurred.

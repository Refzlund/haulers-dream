## Finding and correction

The v3 read-only XML query compared the saved robot's `id` with `actor.thingIDNumber`. Native `Thing.ExposeData` saves the string `ThingID`, which is the def name followed by that number. The v3 query would therefore reject a correctly saved native robot. The author preserved v3 and changed the query to `actor.ThingID` in v4. Independent diff inspection confirms that this is the only scene change; the controller's only v3-to-v4 changes are its two exact host SHA pins, and the build script changes only its output directory. No further readiness blocker was found.
